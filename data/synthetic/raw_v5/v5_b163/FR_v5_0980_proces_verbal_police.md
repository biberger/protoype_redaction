Qualification

Les faits constatés sont susceptibles de constituer une escroquerie au sens des [[legal_norm|articles 313-1, 313-2 et 441-1 du Code pénal]], ainsi qu'un blanchiment au sens de l'[[legal_norm|article 324-1 du Code pénal]]. La qualité d'auteur est appréciée au regard de l'[[legal_norm|article 121-4 du Code pénal]] et de l'[[legal_norm|article 121-6 du Code pénal]]. Une enquête sur les infractions en bande organisée peut être ouverte sur le fondement de l'[[legal_norm|article 706-73 du Code de procédure pénale]].

Lecture faite, les personnes entendues persistent dans leurs déclarations et signent avec nous.
